# ことのかげ — 紹介映像

アプリの映像。1920×1080・30fps・約120秒、字幕とナレーション（Gemini TTS）。Remotion 4 で作る（アプリとは別のプロジェクト）。
作り方は姉妹の映像（ことのえだ `../../keigo/promo`・ことのおと `../../chinese/promo` など）にそろえた：アプリの画面を描き直し、
その横に一文ずつ言葉を置く。録画は使っていない。行・まとまり・聞こえ方はアプリの中身（`../src/content`）とその関数
（`../src/lib/text.ts` の `wordsOf`・`wordsIn`）、言葉は `../src/lib/i18n/ja.ts`、声はアプリ自身の声（`../public/audio`）から。

見る人：中学・高校で英語を学び、読めば分かる英文は多いのに、ふつうの速さの会話は聞き取れず、言いたいことがあってもその場で
出てこない人。一つの会話を 聞く → 気づく → 追いかける → 返す と通り、追いかけたまとまりが日をあけて別の会話でまた聞こえて
くる流れを、アプリの画面で見せる。

| | 画面 | 映像の言葉 |
|---|---|---|
| 問い | サムの一行（ramen.3）が字幕のまま。それが 聞く の影（語の長さの棒）になり、サムの声が言うそばから、その語の棒が濃くなる。字幕に戻ると、Want to の下に Wanna、check と out をつなぐ弧 | 読めば、分かる。／でも、ふつうの速さの会話だと、聞こえない。／知らないからではなく、音の形が変わるから。 |
| | わたし：I まで打って止まる | 言いたいことがあっても、その場で、出てこない。 |
| 名前 | アイコンの声の波が墨で描かれ、少し遅れて、その影（青の波）が追いかけて描かれる。ことのかげ | 読めば分かる英語を、電話で使える英語に。 |
| 聞く | 授業のあと（サムとミア）：場面の写真と 流す。写真は顔の帯に下がり、行は言われるそばから影で降ってくる（ramen.1・ramen.2） | 字幕なしで、まるごと聞く。 |
| 気づく | 影が字幕に戻り、まとまりが光り（週末の会話で出会った though は紫）、聞こえ方（Wanna・gotta・弧）が付く。I've been meaning to を押すとシート、ゆっくり（0.75 倍）でそこだけ | 読めば分かるのに、聞こえなかったところ。／まとまりだけを、ゆっくりでも。 |
| 追いかける | 2周目（字幕 うすく）。録って追いかける：ミアの ramen.4 に、少し遅れてわたしの声。ボタンの輪はその声の大きさで太る。聞き取って、行ごとに聞こえた語は濃く、聞こえなかった語（out、been meaning to）は薄く。字幕は なし に | 声のすぐあとを、自分の声で。／機械の耳に、何と聞こえたか。 |
| 返す | 自分で返す：サムのひとことと、あなたの事情（ミア）。「I have バイト today... How about Saturday?」と打って送る。直した文（バイト に線、work に下線）がわたしの声で、サムの返事がサムの声で | 追いかけたら、相手のひとことに返す。／英語が出ないところは、日本語のままで。／直った英語が、手本の声になる。 |
| また出会う | 数日後、土曜の準備（ノラとレオ）を 気づく で。週末と授業のあとで出会ったまとまり（kind of・though・Text me・Will do・can we）は紫。行を押して、ノラとレオの声で（speakers.5・6） | 数日後、別の会話・別の声で。 |
| 自分 | できたこと：「授業のあと」のこの行が、全部聞こえた（ramen.4） | 前は聞こえなかった行が、日をあけて聞こえた日。 |
| 終わり | 名前、タブ（追いかける・会話・自分） | 登録はいりません。記録はこの端末に残ります。 |

## 本物と、映像のための例

- 追いかける の結果は、アプリと同じ処理の本物（`scripts/follow.mjs` → `src/follow.json`）。ここに学習者はいないので、学習者の
  声の代わりに、アプリのわたしの声（女性の声 Leda：設定のはじめの声）が「授業のあと」を追いかける。1周目は、聞こえていなかった
  所（ramen.3 の out、ramen.4 の been meaning to）を言えなかった人として、そこを抜いて読ませた。録音の組み方（行は 550ms あけて
  流れ、録音は1行目の 250ms 前から）、機械の耳への頼み方（`/api/hear` と同じ gpt-4o-transcribe と prompt、行は渡さない）、
  会話まるごとを一度に `heardWords` で並べて行ごとに分けるところは `Follow.tsx` のとおり。機械の耳は「Oh, I've try it.」
  「Wanna check that new ramen place」と書き、薄い語はそこから出た。日をあけての ramen.4（この行だけ）は全部言わせて、全部
  聞こえた（自分 の できたこと）。映像で鳴る影の声は、この 1周目の ramen.4 そのもの。
- 映像は ramen.4 のところから見せている（2周目の一続きの録音のうち、その行だけを切り出して見せた。結果は会話まるごとのもの）。
- 返す の直しと返事は、アプリの `/api/turn` と同じ頼み方で返ってきた本物（`scripts/turn.mjs` → `src/turn.json`、gpt-5.5・low、
  `turn-core.ts` の `turnPrompt`・`cleanTurn`）。声は `/api/say` と同じく `../src/lib/tts.ts` の `speak` で（直した文はわたしの声、
  返事はサムの声）。
- 紫は アプリの `metBefore` と同じ考え：学ぶ人は「週末どうだった？」→「授業のあと」の順に済ませ、数日後に「土曜の準備」を
  会話の一覧から選んだ、とした。
- 自分 の数（追いかけた会話 3・周 12・自分で返した文 2）と、できたこと の日付（10月30日）は、映像のために置いた例
  （`src/scenes/Story.tsx` の `EXAMPLE`）。

## 音

- ナレーション：台本は `voice/lines.json`（画面の字幕とは別の、耳で聞く文。同じ音で紛れた行は言い方を替えた：台本の note）。
  Gemini TTS（`gemini-3.1-flash-tts-preview`、声 Kore）を Vertex AI で。鍵はアプリの `.env.local`（`GOOGLE_SERVICE_ACCOUNT_KEY`・
  `GOOGLE_CLOUD_PROJECT`・`GOOGLE_CLOUD_LOCATION`、ことのあめ と同じサービスアカウント）。鍵はこのリポジトリに置かない。
  `--check` で書き起こして台本と並べる。欠番：V11（理由は台本に）。
- 英語の行は、アプリの声そのもの（`public/app`：アプリの `public/audio` のクリップ）。Remotion の ffmpeg には ebur128 が無いので、
  声のある所の大きさを `scripts/wav.mjs` で測ってそろえる（およそ -17 dBFS、ピークは -1 dBFS まで。ナレーションはおよそ -16）。
  影の声（わたしの声）は手本の下に聞こえるよう -6 dB（`src/Promo.tsx` の SHADOW）。
- 映像の時は、声の長さから決まる（`src/voice.json`・`src/audio.json`・`src/follow.json`・`src/turn.json`。`src/timeline.ts` は声が
  言い終わってから次へ）。英語の声の上にナレーションは重ねない。声のあいだは音楽が下がる（`src/Promo.tsx` の DUCKING）。
  声を作り直したら `music` も走らせ直す。
- 音楽と小さな音は `scripts/music.py`（ことのえだ の映像のものを写し、種だけ変えた）。だれかの曲は使っていない。
- 耳で聞いての確かめ（声の感じ・速さ・影の声の聞こえ方・音量のつり合い）は、機械ではできない。

## 作り方

```bash
cd promo
npm install
npm run assets     # アイコン、場面の写真、アプリの声とまとまりの音、アプリの言葉（src/copy.json）、字（映像に出てくる字だけに切る。Python の fontTools）
npm run follow     # 追いかける：わたしの声で追いかけて、機械の耳に聞かせる（src/follow.json。作り直すなら -- --force）
npm run turn       # 返す：直しと返事と、その声（src/turn.json。作り直すなら -- --force）
npm run voice      # ナレーション（まだ無いものだけ。--force・--only V01・--check・--durations）
npm run music      # 音楽と小さな音（Python と numpy。映像の区切りに合わせて作る）
npm run studio     # 見ながら直す
npm run render     # out/kotonokage-promo.mp4
npm run stills -- 30 1380 2120     # 1コマずつ out/stills に
```

- 鍵の要るもの（follow・turn・voice）はアプリの `.env.local` を読む。follow と turn は作ったものを残し、同じ文なら作り直さない。
- 画面はアプリの CSS と言葉から描き直している（`src/ui.tsx`、`src/scenes/`）。電話の幅 600 px を 1.5 倍で見せる。アプリの見た目や
  言葉を変えたら、ここも変える（`npm run assets` で `src/copy.json` の言葉は取り直せる）。
- 字（IBM Plex Sans・IBM Plex Sans JP・しっぽり明朝）は映像に出てくる字だけに切ってある。言葉を変えたら `assets` を走らせ直す。
  Plex に無い字（details の三角など）は字にせず描いている。
- 色は `remotion.config.ts` で bt709・yuv420p（姉妹と同じ）。
- 見せる中身は `../CONCEPT.md` のとおり：点数・一致率・速さの数字・連続記録は出さない。
